이 포트폴리오를 만든 프롬프트

이 사이트는 아래의 프롬프트를 출발점으로, 디자인과 인터랙션을 반복해서 수정하며 만들었습니다.

  1. 전체 콘셉트

    “HTML, CSS, JavaScript로 우주 공간에 작품이 떠 있는 듯한 인터랙티브 시각디자인 포트폴리오를 만들어 줘.”

  2. 프로젝트 탐색

    “현재 작품은 화면 중앙에 크게 배치하고, 주변 작품은 뒤쪽 공간에 작게 배치해 줘. 이동할 때 X축과 Z축, 크기와 투명도가 함께 변하도록 해 줘.”

  3. 다양한 조작 방식

    “드래그, 마우스 휠, 키보드 방향키, 좌우 화살표로 프로젝트를 탐색할 수 있게 해 줘. 첫 작품과 마지막 작품 사이에서만 이동하고 무한 반복은 사용하지 마.”

  4. 시작 화면

    “GRAPHIC DESIGN PORTFOLIO 타이틀과 중앙의 START 버튼, 하단 인적사항으로 구성된 미니멀한 시작 화면을 추가해 줘.”

  5. 파티클 타이틀

    “기존 타이틀의 글꼴과 형태를 유지하면서 작은 원형 입자로 표현해 줘. 마우스 주변에서는 흩어지고, 클릭하면 충격파가 퍼지며, 이후 스프링처럼 원래 위치로 돌아오게 해 줘.”

  6. 별 배경

    “검은 단색 배경 위에 선명한 별을 배치하고, 마우스와 같은 방향으로 별 배경 전체가 부드럽게 움직이도록 해 줘. 텍스트와 버튼은 움직이지 않게 해 줘.”

  7. 상세 페이지와 화면 전환

    “모든 프로젝트에 하나의 공통 상세 템플릿을 사용하고, 이미지와 설명은 데이터 파일에서 관리하게 해 줘. 화면을 이동할 때는 현재 화면이 서서히 사라지며 다음 화면이 드러나는 페이드를 적용해 줘.”

  8. 디자인과 반응형

    “배경은 #171717, 기본 글자색은 #F5F5F5를 사용해 줘. PC 디자인을 유지하면서 모바일에서는 제목 크기와 줄바꿈, 여백을 화면에 맞게 재구성해 줘.”
