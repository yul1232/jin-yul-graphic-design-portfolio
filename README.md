# 진율 포트폴리오

index.html을 브라우저에서 열면 실행됩니다. 별도의 설치나 빌드 과정은 필요하지 않습니다.

## 최신 수정

- 모바일 가로 화면(가로 방향, 너비 1023px 이하·높이 500px 이하)에만 하단 정보를 이름 / 학교·학과 / 연도 한 행으로 정렬합니다. 학교와 학과 사이의 줄바꿈을 이 구간에서만 숨기고 공백을 두며, 제목·값의 세로 시작점을 통일했습니다. 844×390, 667×375, 568×320, 480×320, 320×240에서 겹침·가로 넘침 없이 확인했습니다. PC·태블릿·모바일 세로의 기존 배치와 다른 요소는 유지합니다.

- 첫 화면 반응형을 개선했습니다. 1024px 이상은 기존 두 줄 제목과 PC 크기 규칙을 유지하고, 768~1023px 태블릿과 320~767px 모바일에서는 GRAPHIC / DESIGN / PORTFOLIO 세 줄로 제목 자체를 크게 배치합니다. 글꼴·굵기·미세 자간 계산은 그대로 사용합니다. 첫 화면 제목과 파티클 색상은 #F5F5F5이며 상세 타이틀 및 나머지 UI 색상은 유지합니다.
- 모바일 START 터치 영역은 최소 132×56px입니다. 하단 정보는 이름·연도를 첫 행, 학교·학과를 둘째 행으로 재구성했습니다. 낮은 화면에서는 첫 화면 내부 세로 스크롤을 허용해 크기를 억지로 줄이지 않습니다.
- 파티클은 기존 글자별 실제 위치를 다시 읽어 세 줄 제목에도 맞춰 재배치됩니다. 1440×900, 1280×720, 1024×600, 1023×768, 834×1112, 768×1024, 767×900, 390×844, 320×568, 667×375, 1366×500에서 가로 넘침·글자 잘림·요소 겹침·파티클 캔버스 크기를 확인했습니다. 결과는 responsive-checks.json에 기록했습니다.

- 프로젝트 설명 본문 바로 아래에 사용 도구 영역을 추가했습니다. 본문과 제목은 36px, 제목과 로고는 16px, 로고 사이는 14px입니다. 로고는 투명 배경의 #F5F5F5 단색 SVG, 26px 정사각형입니다. 설명 펼치기 영역 밖의 독립 항목으로 배치되어 설명을 접어도 항상 표시됩니다. 설명을 펼치면 본문 다음에 표시됩니다.
- `projects.js`의 각 프로젝트에 `tools: ['photoshop', 'illustrator']`처럼 키를 지정합니다. 현재 PROJECT 01에만 두 도구를 지정했고 나머지는 빈 배열입니다. 빈 배열이거나 등록된 도구가 없으면 사용 도구 제목과 로고를 표시하지 않습니다. 추가 프로그램은 `project-tools.js`에 이름과 로고 경로를 등록한 뒤 해당 키를 프로젝트의 tools 배열에 넣으면 됩니다. 로고 파일은 `assets/tools/`에서 관리합니다.

- 타이틀 입자를 더 작고 촘촘한 육각 격자로 변경했습니다. 무작위 점의 겹침을 없애고 중심 간격과 지름을 별도로 계산해 항상 미세한 여백을 남깁니다. 기본 간격은 지름의 약 16%이며 원 전체가 원래 글자 내부에 있는 지점만 사용합니다.
- 화면의 실제 글자 면적에 맞춰 PC 약 16,000개·모바일 약 11,000개 후보를 생성한 뒤 윤곽 밖의 점을 제외합니다. 실제 표시 개수는 글꼴·화면 크기에 따라 달라집니다. 기존 4,000개보다 높은 밀도이며, 호버·탄성 복귀·일렁임·충격파 물리는 변경하지 않습니다. title-sampling.js가 배치만 담당하고 한 번의 Canvas 경로에 점들을 함께 그립니다. 배치 검증은 `node verify-title-sampling.cjs`로 실행합니다.

- 첫 화면 타이틀에만 약 4,000개 점의 파티클 효과를 추가했습니다. cover.js가 계산한 실제 글자별 위치와 기존 CSS 글꼴을 Canvas 마스크로 읽어 원래 글자 내부에 점을 배치합니다. 제목 DOM은 레이아웃과 접근성용으로 유지하며 글꼴·크기·굵기·자간·행간·색상은 변경하지 않습니다.
- title-physics.js는 스프링 복귀, 포인터 반발과 약한 소용돌이, 클릭 위치에서 확장되는 충격파를 계산합니다. title-particles.js/css는 동일한 타이틀 색상으로 점만 그립니다. 충격파에 별도 그래픽·색상은 추가하지 않습니다.
- 기본 일렁임은 1px 미만으로 제한하고, 포인터가 벗어나면 먼저 원래 위치로 정착한 뒤 은은한 일렁임을 재개합니다. 화면 밖·숨긴 첫 화면에서는 렌더링을 멈춥니다. 시스템 동작 줄이기 설정에서는 같은 파티클 형태를 정적으로 표시합니다.
- 리사이즈·글꼴 로딩·제목 재배치 시 파티클을 다시 생성합니다. Canvas 준비에 실패하면 원래 타이틀을 그대로 표시합니다. 물리 로직 검증은 `node verify-title.cjs`로 실행합니다.

- 프로젝트 선택 화면의 전체 화면 포커스 사각형 테두리를 제거했습니다.
- 상세 화면에도 첫 화면과 같은 별 그리기·밝기·크기·분포 및 마우스 레이어 이동을 적용했습니다. 별 레이어는 콘텐츠 뒤에 고정되며 모든 포인터 입력을 통과시킵니다.
- 상세가 로드되면 페이드 중에도 휠 입력을 받을 수 있게 했습니다. 프레임 교체 직후 커서가 움직이지 않아 호스트 문서에 도착하는 휠도 상세 문서로 전달하며, 상세 내부의 정상 휠 이벤트는 그대로 브라우저가 스크롤합니다.

- 첫 화면과 프로젝트 선택 화면에 star-motion.js/css를 적용했습니다. 마우스 좌표와 같은 방향으로 전체 별 레이어가 최대 14px 이내에서 부드럽게 움직입니다. 첫 화면의 별은 프로젝트와 동일한 난수·밀도·크기·밝기를 사용합니다. 프로젝트의 기존 별 그리기와 탐색 애니메이션은 그대로 두고 부모 레이어에 마우스 이동만 합성합니다. UI에는 transform을 적용하지 않습니다. 동작 줄이기 설정에서는 마우스 반응을 생략합니다.

- 프로젝트 화면의 HOME 문구를 '처음 화면으로'로 변경했습니다. 탐색/상세 상단 링크는 navigation.css에서 위치·여백·폰트·자간·행간을 공유합니다. 기존 상세 화면의 PC/모바일 좌표를 기준으로 정렬합니다. 두 링크의 밑줄은 마우스 hover 시에만 같은 두께(2px), 색상(#F5F5F5), 간격(5px)으로 표시됩니다. 클릭 중·화면 전환 중에는 밑줄을 제거합니다. 사각형 포커스 외곽선은 사용하지 않으며 키보드 포커스는 은은한 글자 강조로 표시합니다.

- 타이틀의 글꼴·크기·굵기는 유지합니다. DESIGN의 D–E 사이 실제 글자 윤곽 간격을 Canvas 글꼴 측정으로 계산하고 모든 글자에 같은 간격을 적용합니다. 단어 간격은 따로 관리하며 줄 전체는 Flexbox로 중앙 정렬합니다. 화면 크기가 변하면 다시 측정합니다.
- START → 탐색 → 상세 → 탐색, 탐색 → HOME 모두 page-transition.js와 transition.css를 공유합니다. 다음 화면을 준비한 뒤 현재 화면의 opacity만 1000ms ease-in-out으로 낮춥니다.
- 프레임은 최상위에서 한 단계로만 교체합니다. 페이지를 오갈 때 프레임이 중첩되지 않습니다. 전환 완료 후 이전 프레임을 제거하고 새 화면에 초점을 전달합니다.
- 상세 화면은 자체 문서에서 세로 스크롤을 처리합니다. 프로젝트 탐색용 휠·방향키 이벤트는 상세 문서에 등록하지 않습니다.
- 상세의 뒤로 링크는 선택한 프로젝트 ID를 전달해 위치를 복원합니다. 탐색 화면 왼쪽 상단 BACK TO HOME은 같은 페이드로 첫 화면에 복귀합니다.

## 확인 방법

index.html 실행 → START → 프로젝트 2로 이동 → 카드 클릭 → 상세에서 휠 스크롤 → 상단의 뒤로 → 02/06 위치 확인 → BACK TO HOME 순서로 확인할 수 있습니다. 공통 전환 단위 검증은 `node verify-transition.cjs`로 실행합니다. HTTP 미리보기는 `node preview.cjs` 실행 후 http://127.0.0.1:4173 에서 확인합니다.

- index.html, cover.css, cover.js: 시작 화면과 프로젝트 화면이 드러나는 페이드 전환.
- cover-data.js: 이름, 학교, 학과, 연도, 제목, 전환 시간을 변경합니다.
- explore.html, style.css, script.js: 별 배경과 카드 탐색. 화살표·드래그·방향키·휠을 지원합니다.
- page-transition.js, transition.css: 네 경로에서 공유하는 페이드 전환과 프레임 교체.
- project.html, project.css, project.js: 공통 상세 템플릿, 소개 펼치기, 작업물 세로 스크롤.
- projects.js: 프로젝트 배열. id, title, category, year, thumbnail, cover, description, images 속성을 관리합니다.
- assets/: 작품 이미지를 저장합니다.

projects.js의 배열에 항목을 추가·삭제하거나 순서를 바꾸면 카드와 탐색 범위가 자동으로 반영됩니다. thumbnail에는 메인 이미지, cover에는 상세 대표 이미지, images에는 작업물 경로 배열을 입력합니다. 빈 이미지 경로는 플레이스홀더로 표시합니다. 기본 작업물은 5개입니다.

배경은 #171717, 기본 흰색은 #F5F5F5입니다. 기본 전환 시간은 시작/상세 진입 1000ms, 카드 이동 550ms입니다. 시스템의 동작 줄이기 설정을 지원합니다. 실제 작품 콘텐츠는 포함하지 않았습니다.
